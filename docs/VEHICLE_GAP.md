## 1. 저장소 구조와 빌드 상태

| 구분 | 위치 | 상태 |
|---|---|---|
| 웹 프로토타입(차량 1600×900 + 모바일 겸용) | `web/` (Vite·React·TS) | 빌드·단위 39개·E2E 30단계 통과 |

## 3. SDK에 맡겨야 해서 ‘구현 완료’로 표시하지 않은 것

- 내장 내비 경로 안내 시작·재개, 경유지 추가, 도착 이벤트 → Pleos **NaviHelper**(빌드 플래그 `mungroad.usePleosSdk`, 실제 키·에뮬레이터 필요). 웹/Stub에서는 ‘데모 내비’ 또는 ‘지도 앱 길 안내’로만 표시
- 기어·속도·주차 상태 → Pleos **Vehicle** / AAOS Car API
- 주유소 검색 → 내비 POI 연동 후(현재 ‘내비 연동 후’ 표시)
- 운전자 주의 분산 정책: 주행 중 사진·프로필·배경 편집 잠금, 추천 3곳 제한, 팝업 없음(웹·Android 모두 같은 규칙)

## 4. 여행 상태(공통) 매핑

| 공통 상태 | 웹 `Trip.phase`/엔진 | Android `TripPhase`/`TripStatus` |
|---|---|---|
| PLANNED | (여행 계획 저장 — 모바일 단계에서 추가) | PREPARING |
| DRIVING | outbound/returning + driving | OUTBOUND/RETURNING + DRIVING |
| RESTING | 엔진 resting | RESTING |
| AT_DESTINATION | at-destination | AT_DESTINATION |
| COMPLETED | completed | COMPLETED |
| CANCELLED | discard(기록 삭제) | — (🔜 상태로 남기기) |

한 여행(Trip) 안에 여러 주행 구간(DriveLeg: 가는 길·여행지 내 이동·돌아가는 길)과 방문 장소가 연결됩니다. 도착 이벤트 id는 `TRIP_ARRIVED:{tripId}:{legId}`로 구간마다 하나입니다.
