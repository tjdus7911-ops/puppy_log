## 16. 품질·예외 처리

| 상황 | 처리 |
|---|---|
| 위치 권한 거부 | 오류 없이 수동 기록 모드 안내 (E2E 확인) |
| GPS 신호 손실 | 30초 이상 수신 없으면 경고 배너, 끊긴 구간은 주행 시간 추정 안 함 |
| 네트워크 실패 | 장소: 오류 화면+다시 시도 / 일기: 템플릿으로 대체 |
| 장소 검색 결과 없음 | 빈 상태 화면 |
| 앱 재실행·여행 중 종료 | 4초마다 + 페이지 숨김 시 스냅샷 저장 → 재실행 시 자동 복원 (E2E 확인) |
| 중복 여행 시작 | 메모리·저장소 이중 확인 (E2E 확인) / Room은 트랜잭션 |
| 휴식 타이머 중복 | 엔진에서 이미 휴식 중이면 무시 (단위 테스트) |
| 잘못된 좌표 / 거리 급증 | (0,0)·범위 밖·정확도 80m 초과·220km/h 초과 이동 제외 (단위 테스트) |
| 사진 선택 취소 | 아무 변경 없음 |
| 데이터 저장 실패 | 토스트 안내, 경로는 다음 주기에 재시도 |
| 화면 회전·크기 | 모바일 세로 / 900px 이상 가로 2열 레이아웃 |

> 참고: 첨부된 요청서는 16장 마지막 줄("위치…")에서 잘려 있어, 그 이후 내용이 있었다면 반영되지 않았습니다.

## 알려진 한계
- 웹 지도는 해안선만 있는 오프라인 SVG입니다(도로·지명 없음). Android 단계에서 지도 SDK로 교체 예정.
- 지역 판정은 시·군 대표 좌표 66곳 중 가장 가까운 곳을 고르는 근사 방식입니다.
- 웹에서는 백그라운드 위치 기록이 브라우저 정책에 따라 멈출 수 있습니다(Android는 포그라운드 서비스로 해결 예정).
- 데모 모드를 높은 배속으로 돌리다 새로고침하면 마지막 저장 시점(최대 4초 분량)부터 이어집니다.
