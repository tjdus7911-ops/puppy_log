# 반려견 탑승 안전 안내 · 차량 상태 연동 (v1.2 · 2026-11-12, 기획서 수정본 반영)

> 창문·더위 안내는 보호자의 확인을 돕는 보조 안내이며 차량의 기본 안전 기능을 대신하지 않습니다.
> 창문과 문은 상태만 읽고 움직이지 않습니다. 차량 제어는 **에어컨 켜기 한 가지**뿐이며, 보호자가 버튼이나 음성으로 동의할 때만 실행합니다.

## 1. 차량 데이터 (`domain/cabin.ts` · `CabinState` / `CabinCapabilities`)
| 데이터 | 출처(기획서 5장) | 쓰임 |
|---|---|---|
| 속도·기어·시동 | AAOS `PERF_VEHICLE_SPEED`·`GEAR_SELECTION`·`IGNITION_STATE` | 주행·일시 정차·주차 구분 |
| 바깥 기온 | AAOS `ENV_OUTSIDE_TEMPERATURE` | 더운 날 안내 |
| 뒷좌석 창문 열림 비율 | Vehicle SDK Window | 머리 내밀기 안내 |
| 뒷문 열림 | Vehicle SDK Door | 주차 중 휴식 시작 확인 |
| 에어컨 상태·켜기 | Vehicle SDK HVAC | 더운 날 켜기 제안(동의 시만 켬) |
| 주행 거리계 | Vehicle SDK Odometer | 이동 거리(미지원·데모는 위치 기록) |
| 주차 브레이크 | Vehicle SDK Brake | 주차 판별 보강 |
| 방향지시등·차량 경고 | Vehicle SDK TurnSignal·Safety | 작동 중 알림 미루기 |

Vehicle SDK 도메인은 여행을 시작할 때 Provider 의 `cabinCapabilities` 로 한 번 확인해 `Trip.vehicleCaps` 에 저장합니다. 지원하지 않는 도메인의 안내는 화면과 알림에서 숨기고, 나머지 기능은 그대로 씁니다.

## 2. 안내 규칙 (`evaluateCabin`, 한 번에 하나)
| 안내 | 조건 | 문구 | 우선순위 |
|---|---|---|---|
| 뒷좌석 창문 | 주행 중 뒷창 50% 초과(20% 이하로 닫히면 다시 안내 가능) | "뒷좌석 창문이 많이 열려 있어요. 사슴이가 머리를 내밀 수 있으니 조금 닫아 주세요." | 안전 |
| 더위 | 주행 중 바깥 28℃ 이상(단두종 25℃) + 에어컨 꺼짐, 구간당 한 번 | "바깥이 31도예요. 사슴이를 위해 에어컨을 켤까요?" (제어 미지원이면 "켜 주세요") | 안전 |
| 휴식 중 더위 | 휴식 중 + 더운 날 | "더운 날이에요. 사슴이에게 물을 주고 그늘에서 쉬어 가세요." | 화면 |
| 뒷문 휴식 확인 | 주차 중(신호 대기 제외) 뒷문이 열리는 순간, 정차당 한 번 | "휴식 시작할까요?" → 예: 휴식 시작(`RestSession.startMethod = 'door'`) | 휴식 |
| 내리기 전 확인 | 주차(또는 도착) 후 시동을 끄는 순간, 이번 정차에서 뒷문이 한 번도 열리지 않았으면 | "사슴이를 내리셨나요? 잠깐 차에 두고 내리면 펫 모드를 켜 주세요." → [함께 내렸어요] [잠깐 두고 내려요 → 펫 모드 안내] | 안전 |
| 휴식 시작 → 펫 모드 안내 | 휴식을 시작하면(버튼·음성·뒷문) | "사슴이를 잠깐 차에 두고 내리시나요?" → 두고 내리면 펫 모드 켜는 방법(P단 → 홈 화면 펫 모드 → 온도 설정·대기 화면 확인) | 화면 |
| 알림 미루기 | 방향지시등 작동·차량 경고 중 | 새 음성 안내를 대기열에 두고 끝나면 재생(30초 지나면 버림) | — |

기준 온도(28℃·25℃)와 창문 기준은 **초안**이며 휴식 간격과 함께 출시 전 수의사 자문으로 확정합니다.
음성 우선순위는 안전(돌발·창문·더위) → 휴식 → 장소 추천입니다. 탑승 안전 안내가 떠 있으면 장소 제안은 기다립니다.
응답이 없으면 안내 카드는 자동으로 닫힙니다(15초, 묻는 안내는 30초).

### 펫 모드에 대해
- 현대·기아 일부 차량(사양 적용 시)의 기능으로, 반려동물을 차 안에 잠시 두고 내릴 때 실내 환경을 맞춰 줍니다. 마이현대(블루링크) 가입·통합계정 연동이 필요하고 'P'에서만 실행됩니다.
- **멍로드는 펫 모드를 직접 켜지 않습니다.** 외부 앱이 펫 모드를 실행할 수 있다는 Pleos 문서 근거를 확인하지 못했기 때문에, 켜는 방법만 안내합니다. 펫 모드 사양이 없는 차량(`petMode:false`)에서는 "차 안에 혼자 두지 마세요"만 안내합니다.
- 주행 중은 멍로드, 주차 중은 펫 모드가 맡아 역할이 이어집니다.

## 3. 기록
- `Trip.safetyLog`: 안내 종류·응답(예/아니요/무응답)
- `RestSession.startMethod`: 버튼 · 음성 · 뒷문 열림 확인 (여행 상세에 표시)
- `RestSession.petStayedInCar`: 휴식 중 반려견을 차에 두고 내렸는지(펫 모드 안내)
- `Trip.placeSuggestLog`: 장소 제안과 수락 여부

## 4. 차량 앱 지표 (`domain/metrics.ts`, 마이페이지)
| 지표 | 정의 | 목표(12개월 / 36개월) |
|---|---|---|
| 휴식 알림 응답률 | 도달 알림 뒤 휴식 시작·휴식지 찾기로 이어진 비율 | 50% / 60% |
| 장소 제안 수락률 | 동반 장소 제안이 들르기(경유지)로 이어진 비율 | 15% / 20% |
| 여행 기록 완료율 | 시작한 여행이 마무리·저장까지 이어진 비율 | 70% / 80% |

프로토타입은 이 기기 기록으로 계산합니다(실제 여행이 없으면 데모 여행). 출시 후에는 익명 통계로만 집계하고 위치·경로는 쓰지 않습니다.

## 5. 데모
- 가는 길 15km 지점: 뒷좌석 창문 60% 열림 → 24km에서 닫힘
- 가는 길 몇 지점에서 방향지시등(알림 미루기)
- 오는 길: 바깥 27℃ → 31℃, 에어컨 꺼짐
- 상태별 화면 테스트 시트 → 차량 상태 이벤트: 뒷좌석 창문 열림 · 더운 날·에어컨 꺼짐 · 휴게소 주차·뒷문 열림 · 방향지시등 작동 · 주차·시동 끔(뒷문 안 열림)
- 모든 차량 상태 화면에 '데모' 표시

## 6. Android(Pleos) 이식 시 할 일 — 미구현
- `PleosVehicleDataProvider`: CarPropertyManager 구독(속도·기어·시동·외기 온도), Vehicle SDK 도메인별 `checkXXXCapability` → `cabinCapabilities`
- 사용하는 도메인의 Pleos 권한만 선언, 차종명으로 분기하지 않음
- HVAC 제어 권한은 App Market 사전 협의·승인 범위 안에서만
- 오디오 포커스 정책 + TurnSignal·Safety로 알림 지연
