# 반려견 맞춤형 휴식 추천 (v1.0 · 2026-11-12)

> 원칙: 이 기능은 **진단·치료 지시가 아닙니다.** 앱은 실제 피로도나 건강 상태를 측정하지 않으며,
> 나이·견종·체중으로 휴식 간격 숫자를 계산하지 않습니다. 수의사 안내와 보호자 설정이 항상 우선합니다.

## 1. 근거 조사 결과
| 출처 | 내용 | 앱에서의 사용 |
|---|---|---|
| AAHA (미국동물병원협회) 반려동물 여행 안내 | "몇 시간마다 멈추라"는 일반 권고, 구체적 분 단위 없음 | 건강 특이사항 안내 문구의 출처 |
| AVMA (미국수의사회) 반려동물 여행 안내 | 정기적으로 정차 계획, 멀미는 수의사 상담 | 멀미 안내 문구의 출처 |
| 상업 사이트(펫 쇼핑몰·블로그) | "2–3시간마다" 등 | **사용 안 함** (권위 있는 출처 아님) |

나이·견종·체중별 휴식 간격을 제시하는 권위 있는 수의학 기준은 찾지 못했습니다. 그래서 앱은 이런 숫자를 만들지 않습니다.

## 2. 데이터 구조 (`web/src/domain/restCare.ts`, `models.ts`)
- `Pet.care?: PetCare`: 모두 선택 입력이며, 기기(IndexedDB)에만 저장됩니다.
  - `senior: boolean|null`: 보호자가 직접 선택합니다. 앱이 나이로 판정하지 않습니다.
  - `motionSickness`, `travelAnxiety`: `'none'|'sometimes'|'often'|null`
  - `healthNotes`, `vetAdvice`: 자유 텍스트
  - `vetRestIntervalMinutes: number|null`: 수의사가 안내한 간격을 보호자가 입력합니다 (30–240).
- `Pet.breed?`: 표시용입니다. 계산에는 쓰지 않습니다.
- `Trip.restPolicy`: 출발 시점에 확정한 `{intervalMinutes, basis, petId, reasons[], prompts[], decidedAt}`
- `Trip.restRecoLog[]`: 추천 이력 `{at, kind:'soon'|'due', intervalMinutes, basis, drivenMinutes, response:'find'|'later'|'rest'|'none'}`
- `Trip.restIntervalChanges[]`: 간격 변경 이력 `{at, from, to, reason:'pet-condition'|'vet'|'schedule'|'other'}`
- `AppSettings.mainPetId`: 대표 반려견입니다. 음성과 문구의 이름에 씁니다.

## 3. 추천 규칙
1. **간격 결정 우선순위**: 수의사 안내 간격 → 보호자 설정 간격 → 앱 기본값 90분. 앱 기본값은 "의학 기준 아님"으로 표시합니다.
2. **여러 마리**와 함께 탈 때는 가장 짧은 간격을 쓰고, 그 반려견을 이유로 표시합니다.
3. **케어 플래그**(노령견·멀미·불안·건강 메모·수의사 메모)는 간격 숫자를 바꾸지 않습니다. 출발 전 확인 문구와 음성 표현만 바꿉니다.
4. 모든 규칙에는 `source`와 `expertReviewed`가 붙습니다. 현재 전문가 검토 완료 표시는 `vet-advice`(보호자 입력 그대로 사용) 하나뿐입니다.
5. 출발 전이나 주행 중에 보호자가 간격을 바꾸면 basis는 `guardian`이 되고, 변경 이유가 기록됩니다.

## 4. 음성·문구
- 곧 휴식: "곧 사슴이가 쉬어갈 시간이에요."
- 휴식 시간: "사슴이가 쉬어갈 시간이네요. 가까운 휴식 장소를 찾아볼까요?"
- 케어 설정이 있을 때: "사슴이의 여행 케어 설정을 고려하면 잠시 쉬어가는 게 좋겠어요. 가까운 휴식지를 안내할까요?"
- 장소를 찾았을 때: 동반 가능 여부가 확인된 경우에만 "반려견 동반이 가능한"이라고 말합니다. 확인되지 않았으면 "동반 여부는 확인이 필요해요"라고 말합니다.
- 이름은 실제 반려견 이름을 쓰고, 조사(이가/가, 와/과)를 자동으로 맞춥니다. 테스트로 '피곤', '측정', '진단' 같은 표현이 들어가지 않는지 검사합니다.

## 5. UI 변경 범위
| 화면 | 변경 |
|---|---|
| 반려견 등록·수정 | 견종 필드, 접이식 "여행 케어(선택)" 섹션, 고지 문구, 케어 정보 지우기 |
| 여행 시작(모바일 4단계, 차량 3단계) | 간격과 근거, 여러 마리일 때 이유, 확인 문구, "측정값 아님 / 휴대폰 위치 기준" 안내 |
| 주행 대시보드(차량) | 휴식 시간 줄에는 이름, 메시지, **[가까운 휴식 장소 찾기] [나중에 알림]**만 표시합니다. [휴식 시작]은 정차 중에만 보입니다. |
| 주행(모바일) | 같은 두 버튼 |
| 간격 변경 시트 | 변경 이유 칩, 변경 이력 |
| 장소 상세 | 주차, 운영 시간, 야외 동반. 모르면 "확인 필요"로 표시합니다. |

## 6. 외부 연동 필요사항 (미구현)
- **Pleos TTS·NaviHelper**: 차량 음성 출력, 경유지 추가, 실제 주행·정차 상태. 지금은 웹 SpeechSynthesis와 데모 경유지를 씁니다.
- **장소 API**: 반려견 동반, 주차, 운영 시간, 시설 정보. 카카오 키워드 검색만으로는 동반 여부를 확정할 수 없어 별도 데이터(한국관광공사 반려동물 동반여행 API 등)를 서버 경유로 연동해야 합니다.
- **수의사(전문가) 검토**: 확인 문구와 규칙. 검토 전까지는 `expertReviewed:false`로 둡니다.
- **서버 동기화**: 추천 이력과 간격 변경 이력의 백업 및 기기 간 동기화. 지금은 기기 로컬에만 있습니다.
- **차량 미연동 고지**: 차량이 연결되지 않은 동안 주행 시간은 휴대폰 위치·데모 기준이라고 화면에 표시합니다 (구현됨).
